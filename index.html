03 / CONHEÇA A API

Poucos métodos.
Muitas possibilidades.

Documentação completa ↗
VMasker(elemento)+

Vincule a máscara a um campo ou a uma lista de campos. Use .maskMoney(), .maskPattern(), .maskNumber() ou .maskAlphaNum().

.unMask() remove o vínculo e a formatação.

VMasker.toMoney(valor, opções)+

Formate moeda sem precisar de um campo. Ajuste precisão, separadores, prefixo, sufixo e sinal.

VMasker.toMoney('123456', { unit: 'R$' });
// 'R$ 1.234,56'
VMasker.toPattern(valor, padrão)+

Combine dígitos, letras e separadores para criar seu formato.

VMasker.toPattern('12345678901', '999.999.999-99');
// '123.456.789-01'
VMasker.toNumber(valor)+

Preserve dígitos e um sinal negativo inicial, descartando os demais caracteres.

VMasker.toNumber('-12abc34'); // '-1234'
VMasker.toAlphaNumeric(valor)+

Mantenha letras e dígitos ASCII, além dos espaços.

VMasker.toAlphaNumeric('A-1 B_2!'); // 'A1 B2'
